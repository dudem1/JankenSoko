# JankenSoko

A puzzle game that combines classic sokoban gameplay with the logic of rock-paper-scissors.

![small animated demo](https://img.itch.zone/aW1nLzI3Mjc1MDk1LmdpZg==/original/0tp0Ki.gif)

## Controls 🕹️

Movements: **WASD** or **Arrow keys** or **Swipe**  
Restart level: **R key**  
Undo step: **Space key**

## Development 🛠️

The game was developed using Godot 3.6.2.  
Music was created with [BeepBox](http://beepbox.co).  
Graphics were designed in Adobe Photoshop.  
Special thanks to **Машка** for helping with the development.
